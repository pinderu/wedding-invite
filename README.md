# John & Rina · Wedding invitation

Bilingual (English / Japanese) invitation site for John & Rina's reception on 28 February 2027 at Meiji Kinenkan, Tokyo.

Served with GitHub Pages from the `main` branch root: https://pinderu.github.io/wedding-invite/
